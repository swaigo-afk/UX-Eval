## Instructions

### Step 3 — DESKTOP CRITIQUE

Write Section 3. Begin with a one-paragraph design summary (layout, components, content hierarchy). Then run the critique for each persona in this order: Seeker, Regular Bidder, Casual Browser, Curious Owner, Consignor.

For each persona, follow this structure exactly:

- **What they need from this page:** 2–3 sentences.
- **What works:** Bullet list. Only include genuine strengths — do not pad this section.
- **What fails:** Numbered list. Each item: bold label, then explanation connecting the failure to the persona's documented behaviour and to the data where available. Flag each item 🟥/🟨/🟩.
- **Severity:** One of: Critical / High / Medium / Low — with flag.
- **Recommendation:** Concrete, actionable. One paragraph.

Close with a **"Journey Data Implications — Desktop"** section: 3–5 short paragraphs connecting the journey metrics (from Module 3 output) to the design failures identified.

Close with a **"Desktop Overall Verdict"**: Which persona is best served, which is worst served, and the single highest-impact change.
