## Instructions

### Step 4 — MOBILE CRITIQUE

Write Section 4. Same structure as Section 3 but for the mobile layout. Begin with a design summary describing the mobile viewport (device tested, above-fold content, notable mobile-specific elements). Run the same five-persona critique in the same order: Seeker, Regular Bidder, Casual Browser, Curious Owner, Consignor.

For each persona, follow this structure exactly:

- **What they need from this page:** 2–3 sentences.
- **What works:** Bullet list. Only include genuine strengths — do not pad this section.
- **What fails:** Numbered list. Each item: bold label, then explanation connecting the failure to the persona's documented behaviour and to the data where available. Flag each item 🟥/🟨/🟩.
- **Severity:** One of: Critical / High / Medium / Low — with flag.
- **Recommendation:** Concrete, actionable. One paragraph.

**Important:** If a mobile issue duplicates a desktop issue but is more severe, say so explicitly and escalate the severity.

Close with **"Journey Data Implications — Mobile"**: 3–5 short paragraphs connecting the journey metrics to the mobile-specific design failures identified.

Close with **"Mobile Overall Verdict"**: Which persona is best served, which is worst served, and the single highest-impact change.
